Student Management System
📌 Description

The Student Management System is a web-based application developed to manage student academic and personal information efficiently.

The system allows an administrator to add, view, update, search, and delete student records. It also provides functionality to manage student marks and calculate academic results.

This project was developed as a learning project to understand web development, database management, CRUD operations, and backend programming using Python and Flask.

✨ Features

Admin login

Add student records

View student records

Search students

Update student information

Delete student records

Add subject marks

Calculate total marks

Calculate percentage

Display student results

Store information in a database

Responsive user interface

🚀 How to Run the Project
1. Clone the repository
git clone YOUR_REPOSITORY_URL

2. Open the project directory
cd student-management-system

3. Create a virtual environment
python -m venv venv

4. Activate the virtual environment

Windows:

venv\Scripts\activate


Mac/Linux:

source venv/bin/activate

5. Install dependencies
pip install -r requirements.txt

6. Run the application
python app.py

7. Open the application

Open the local address displayed by Flask in your web browser.
